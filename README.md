## 製品概要
### 背景(製品開発のきっかけ、課題等）
日程調整において、送り手側は回答が得られないと次に進めない+そのストレスが発生する、受け手側は予定を把握して回答するというアクションの認知負荷が高いという問題がある。これに対し、送り手側のストレス/受け手側の認知負荷を軽減することを課題として設定し、インタラクティブなUI、AIによる自動日程調整、ストレス解消機能を備えたアプリを作りました。
