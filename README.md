## 製品概要
### 背景(製品開発のきっかけ、課題等）
日程調整において、送り手側は回答が得られないと次に進めない+そのストレスが発生する、受け手側は予定を把握して回答するというアクションの認知負荷が高いという問題がある。これに対し、送り手側のストレス/受け手側の認知負荷を軽減することを課題として設定し、インタラクティブなUI、AIによる自動日程調整、ストレス解消機能を備えたアプリを作りました。
### 製品説明（具体的な製品の説明）
### 特長
#### 1. 特長1　○△×が自動で入る
カレンダーの予定をもとに、○△×を自動で入れます。理由も表示されるので、違うところだけ直せばOKです。予定の中身は相手に見えません。
返す時間を宣言できる

#### 2. 特長2 回答期限
「今夜21時に返す」のように、返す時間だけ先に伝えられます。幹事には宣言が届き、本人には時間の前にリマインドが届きます。
連打で催促できる
#### 3. 特長3 連打
返事がない人に「はよ〜〜！」を連打して、プレゼントとして送れます。相手が開くと、画面いっぱいに「はよ〜〜！」が降ってきます。

### 解決出来ること
* 返事待ちで日程が決まらない状態を減らせます。
* 予定を確認する手間がほとんどなくなります。
### 今後の展望
* 全員が空いていそうな日を、最初から提案できるようにします。
* Discordなど、ほかのチャットにも通知できるようにします。
### 注力したこと（こだわり等）
* 催促を、気まずくなくしました。
